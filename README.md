# Methods Practice
This is a project to practice methods and learn more about github 
and how to commit to a respository, along with creating a README.md file.

## Prerequisites
- Download and install [visual Studio 2026](https://visualstudio.microsoft.com/downloads/) 
  with the .NET desktop development workload.
- [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)
- Windows OS
